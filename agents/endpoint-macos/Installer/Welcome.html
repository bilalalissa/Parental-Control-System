Choose this Mac’s role

Parent Mac: continue with the default Parent Controller choice.

Child Mac: choose Customize, deselect Parent Controller, and select Child Endpoint.

Quit Safari completely before installing the Child Endpoint. The child endpoint is visible and communicates over the authenticated local network. In-place upgrades retain the protected ad-hoc test identity, active-session schedule enforcement and pairing. The installer stops the old helper and applies a single-use recovery window of no more than ten minutes. It installs Chromium test source at /Library/Application Support/ParentalControlBrowserExtension/Chromium and a visible /Applications/Parental Control Safari.app companion. Domain rules use local hostname matching for new navigations, restored tabs and SPA URL changes, independently of optional tab sharing. Every browser profile still requires explicit adult setup and physical testing. Safari testing additionally requires enabling unsigned extensions from Safari's Develop menu, enabling the extension, and granting website access; Safari may require the unsigned-extension permission again after relaunch. Private/guest profiles, pre-login enforcement and whole-device Internet pause are not provided. This local test package is ad-hoc signed and not notarized. Production automatic extension updates require separately configured supported publication/signing. Stable Developer ID distribution must migrate the ad-hoc endpoint identity back to Keychain and replace the Safari temporary mach-service entitlement.

It never collects command lines, window or document contents, screenshots, keystrokes, passwords, clipboard, camera, microphone, private tabs, query strings, fragments, forms, cookies, page content, or network traffic. This developer candidate is not notarized.
