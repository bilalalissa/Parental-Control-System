Choose this Mac’s role

Parent Mac: continue with the default Parent Controller choice.

Child Mac: choose Customize, deselect Parent Controller, and select Child Endpoint.

The child endpoint is visible and shares disclosed device status, optional application names/bundle identifiers, and family chat over the authenticated local network. It verifies and locally enforces the paired parent's signed schedule, including while offline. Its separately installed visible Chrome/Edge/Arc extension can share bounded tab titles and website origins only after the parent enables browser sharing.

It never collects command lines, window or document contents, screenshots, keystrokes, passwords, clipboard, camera, microphone, private tabs, query strings, fragments, forms, cookies, page content, or network traffic. This developer candidate is not notarized.
